## 1. この論文は何をしたのか（概要）

この論文は **拡散確率モデル（Diffusion Probabilistic Models）** を使って、高品質な画像を生成できることを初めて実証した画期的な研究です。

**拡散モデル**とは、データに少しずつノイズを加えていく「拡散過程（forward process）」と、そのノイズを少しずつ除去して元のデータを復元する「逆過程（reverse process）」の2つのプロセスからなる生成モデルです。

### 主な貢献

1. **高品質な画像生成**: CIFAR10データセットにおいてInception Score 9.46、FIDスコア 3.17（当時の最先端）を達成
2. **デノイジングスコアマッチングとの理論的接続**: 拡散モデルとデノイジングスコアマッチング＋ランジュバン動力学との等価性を発見
3. **漸進的な非可逆圧縮**: サンプリング過程が自己回帰的デコーディングを一般化した漸進的な非可逆伸張として解釈できることを示した

## 2. 背景：なぜ拡散モデルが必要なのか

### 既存の深層生成モデル

深層生成モデルにはすでにいくつかの主要な手法がありました：

- **GAN（敵対的生成ネットワーク）**: 生成器と識別器の競争で学習。高品質だが学習が不安定
- **自己回帰モデル**: ピクセルを1つずつ順番に生成。精度は高いが遅い
- **フロー**: 可逆変換で確率分布を変換。正確な尤度計算が可能だが、アーキテクチャに制約がある
- **VAE（変分オートエンコーダ）**: エンコーダ・デコーダ構造で学習。効率的だがサンプル品質に課題

### 拡散モデルの立ち位置

拡散モデルは Sohl-Dickstein ら（2015）によって提案されていましたが、この論文以前は高品質なサンプルを生成できるという実証がありませんでした。本論文はその課題を解決し、拡散モデルが他の生成モデルと同等以上のサンプル品質を達成できることを示しました。

## 3. 拡散モデルの基本的な仕組み

### 3.1 全体像

拡散モデルは以下の2つのプロセスで構成されます：

<img width="564" height="102" alt="Figure 2: 有向グラフィカルモデル" src="https://github.com/user-attachments/assets/62a7586d-18dd-4fe5-b9ac-1f47a92533cc" />

*Figure 2: 本研究で扱う有向グラフィカルモデル。上段が逆過程（右から左へノイズ除去）、下段が順過程（左から右へノイズ追加）*

#### 順過程（Forward Process）：データにノイズを加える
- 元のきれいなデータ **x₀** から出発
- 各ステップで少しずつガウスノイズを加える
- 最終的に完全なノイズ **x_T** になる（T=1000ステップ）

#### 逆過程（Reverse Process）：ノイズを除去してデータを生成する
- 完全なランダムノイズ **x_T** から出発
- 各ステップで少しずつノイズを除去する
- 最終的にきれいなデータ **x₀** を得る

### 3.2 数学的定式化

#### 潜在変数モデルとしての定義

拡散モデルは以下の形の潜在変数モデルです：

$$p_\theta(\mathbf{x}_0) := \int p_\theta(\mathbf{x}_{0:T}) \, d\mathbf{x}_{1:T}$$

ここで **x₁, ..., x_T** は潜在変数で、元のデータ **x₀** と同じ次元を持ちます。

#### 逆過程（学習対象）

逆過程の同時分布 p_θ(x₀:T) は、学習されたガウス遷移を持つマルコフ連鎖として定義されます：

$$p_\theta(\mathbf{x}_{0:T}) := p(\mathbf{x}_T) \prod_{t=1}^{T} p_\theta(\mathbf{x}_{t-1}|\mathbf{x}_t)$$

$$p_\theta(\mathbf{x}_{t-1}|\mathbf{x}_t) := \mathcal{N}(\mathbf{x}_{t-1}; \boldsymbol{\mu}_\theta(\mathbf{x}_t, t), \boldsymbol{\Sigma}_\theta(\mathbf{x}_t, t))$$

ここで p(x_T) = N(x_T; 0, I)、つまり開始点は標準正規分布です。

> **初学者向け補足**: マルコフ連鎖とは「次の状態が現在の状態だけに依存する」確率過程のことです。つまり x_{t-1} を生成するときに必要な情報は x_t だけです。

#### 順過程（固定・学習しない）

順過程は分散スケジュール β₁, ..., β_T に従ってガウスノイズを徐々に加えるマルコフ連鎖です：

$$q(\mathbf{x}_{1:T}|\mathbf{x}_0) := \prod_{t=1}^{T} q(\mathbf{x}_t|\mathbf{x}_{t-1})$$

$$q(\mathbf{x}_t|\mathbf{x}_{t-1}) := \mathcal{N}(\mathbf{x}_t; \sqrt{1-\beta_t}\,\mathbf{x}_{t-1}, \beta_t\mathbf{I})$$

> **初学者向け補足**: β_t はステップ t で加えるノイズの量を制御するパラメータです。各ステップで元の信号を √(1-β_t) 倍に縮小しつつ、分散 β_t のノイズを加えます。

### 3.3 学習の目的関数（変分下界）

学習は、負の対数尤度に対する変分下界（ELBO）を最適化することで行います：

$$\mathbb{E}[-\log p_\theta(\mathbf{x}_0)] \leq \mathbb{E}_q \left[ -\log \frac{p_\theta(\mathbf{x}_{0:T})}{q(\mathbf{x}_{1:T}|\mathbf{x}_0)} \right] =: L$$

### 3.4 任意の時刻 t での直接サンプリング

順過程の重要な性質として、任意の時刻 t における x_t を x₀ から直接計算できます。α_t := 1 - β_t、ᾱ_t := ∏(s=1 to t) α_s とすると：

$$q(\mathbf{x}_t|\mathbf{x}_0) = \mathcal{N}(\mathbf{x}_t; \sqrt{\bar{\alpha}_t}\,\mathbf{x}_0, (1-\bar{\alpha}_t)\mathbf{I})$$

> **初学者向け補足**: これが非常に便利な性質です。学習時に、1ステップずつ順番にノイズを加える必要がなく、任意の時刻 t のノイズ入りデータを一発で計算できます。これにより学習が効率的になります。

## 4. 変分下界の分解と各項の役割

### 4.1 KLダイバージェンスによる分解

変分下界 L は以下のようにKLダイバージェンスの和に分解できます（分散を低減する形）：

$$L = \underbrace{D_{KL}(q(\mathbf{x}_T|\mathbf{x}_0) \| p(\mathbf{x}_T))}_{L_T} + \sum_{t>1} \underbrace{D_{KL}(q(\mathbf{x}_{t-1}|\mathbf{x}_t, \mathbf{x}_0) \| p_\theta(\mathbf{x}_{t-1}|\mathbf{x}_t))}_{L_{t-1}} + \underbrace{(-\log p_\theta(\mathbf{x}_0|\mathbf{x}_1))}_{L_0}$$

各項の意味：

| 項 | 意味 | 備考 |
|---|---|---|
| **L_T** | 最終ステップでの事前分布とのマッチング | β_t を固定するため学習時は定数 |
| **L_{t-1}** (t > 1) | 逆過程の各ステップの品質 | 学習の主要な対象 |
| **L₀** | 最初のステップ（データの復元精度） | 離散デコーダとして実装 |

### 4.2 順過程の事後分布（トラクタブル）

L_{t-1} の各項はガウス分布同士のKLダイバージェンスなので、閉形式で計算できます。これは順過程の事後分布 q(x_{t-1}|x_t, x₀) がトラクタブルだからです：

$$q(\mathbf{x}_{t-1}|\mathbf{x}_t, \mathbf{x}_0) = \mathcal{N}(\mathbf{x}_{t-1}; \tilde{\boldsymbol{\mu}}_t(\mathbf{x}_t, \mathbf{x}_0), \tilde{\beta}_t\mathbf{I})$$

ここで：

$$\tilde{\boldsymbol{\mu}}_t(\mathbf{x}_t, \mathbf{x}_0) = \frac{\sqrt{\bar{\alpha}_{t-1}}\,\beta_t}{1-\bar{\alpha}_t}\mathbf{x}_0 + \frac{\sqrt{\alpha_t}(1-\bar{\alpha}_{t-1})}{1-\bar{\alpha}_t}\mathbf{x}_t$$

$$\tilde{\beta}_t = \frac{1-\bar{\alpha}_{t-1}}{1-\bar{\alpha}_t}\beta_t$$

> **初学者向け補足**: 「トラクタブル」とは「解析的に計算可能」という意味です。モンテカルロ推定のような近似を使わずに正確に計算できるため、学習が安定します。

## 5. 拡散モデルとデノイジングオートエンコーダの接続

### 5.1 設計上の選択肢

拡散モデルの実装には多くの自由度があります：

1. 順過程の分散 β_t の設定
2. モデルアーキテクチャの選択
3. 逆過程のガウス分布のパラメータ化方法

本論文では、拡散モデルとデノイジングスコアマッチングの明示的な接続を確立し、それに基づいてこれらの選択を行います。

### 5.2 順過程と L_T

分散 β_t は学習パラメータとしてではなく、定数として固定します。したがって順過程に学習パラメータはなく、L_T は学習中定数となり無視できます。

### 5.3 逆過程と L_{1:T-1}

#### 分散の固定

逆過程 p_θ(x_{t-1}|x_t) = N(x_{t-1}; μ_θ(x_t, t), σ²_t I) において、分散 σ²_t は学習しない時間依存の定数とします。

実験では以下の2つの選択肢がほぼ同じ結果を与えました：

- **σ²_t = β_t**: x₀ が N(0, I) に従う場合に最適
- **σ²_t = β̃_t**: x₀ が決定的な1点に集中する場合に最適

これらは逆過程のエントロピーの上限と下限に対応します。

#### 平均のパラメータ化：μ̃ の予測

p_θ(x_{t-1}|x_t) = N(x_{t-1}; μ_θ(x_t, t), σ²_t I) として、L_{t-1} を書き下すと：

$$L_{t-1} = \mathbb{E}_q \left[ \frac{1}{2\sigma_t^2} \|\tilde{\boldsymbol{\mu}}_t(\mathbf{x}_t, \mathbf{x}_0) - \boldsymbol{\mu}_\theta(\mathbf{x}_t, t)\|^2 \right] + C$$

最も素直なパラメータ化は、μ_θ が順過程の事後平均 μ̃_t を直接予測することです。

#### ε予測へのパラメータ変換（本論文の核心）

ここで、x_t の再パラメータ化 x_t(x₀, ε) = √ᾱ_t x₀ + √(1-ᾱ_t) ε（ε ~ N(0, I)）を適用し、順過程の事後平均の公式を代入すると：

$$L_{t-1} - C = \mathbb{E}_{\mathbf{x}_0, \boldsymbol{\epsilon}} \left[ \frac{1}{2\sigma_t^2} \left\| \frac{1}{\sqrt{\alpha_t}} \left( \mathbf{x}_t(\mathbf{x}_0, \boldsymbol{\epsilon}) - \frac{\beta_t}{\sqrt{1-\bar{\alpha}_t}} \boldsymbol{\epsilon} \right) - \boldsymbol{\mu}_\theta(\mathbf{x}_t(\mathbf{x}_0, \boldsymbol{\epsilon}), t) \right\|^2 \right]$$

この式から、μ_θ は以下を予測すべきだとわかります：

$$\boldsymbol{\mu}_\theta(\mathbf{x}_t, t) = \frac{1}{\sqrt{\alpha_t}} \left( \mathbf{x}_t - \frac{\beta_t}{\sqrt{1-\bar{\alpha}_t}} \boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t) \right)$$

ここで **ε_θ はノイズ ε を予測する関数近似器**です。つまり、ネットワークは「ノイズ入りの画像 x_t からどんなノイズが加わっているか」を予測するのです。

このパラメータ化により、L_{t-1} は以下のシンプルな形になります：

$$\mathbb{E}_{\mathbf{x}_0, \boldsymbol{\epsilon}} \left[ \frac{\beta_t^2}{2\sigma_t^2\alpha_t(1-\bar{\alpha}_t)} \|\boldsymbol{\epsilon} - \boldsymbol{\epsilon}_\theta(\sqrt{\bar{\alpha}_t}\mathbf{x}_0 + \sqrt{1-\bar{\alpha}_t}\boldsymbol{\epsilon}, t)\|^2 \right]$$

> **初学者向け補足**: この式はデノイジングスコアマッチングと非常に似ています。複数のノイズスケール（時刻 t でインデックス付け）にわたるスコアマッチングを、拡散モデルの変分推論として自然に導出できたのです。

### 5.4 ランジュバン動力学との接続

x_{t-1} のサンプリングは以下で行います：

$$\mathbf{x}_{t-1} = \frac{1}{\sqrt{\alpha_t}} \left( \mathbf{x}_t - \frac{\beta_t}{\sqrt{1-\bar{\alpha}_t}} \boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t) \right) + \sigma_t \mathbf{z}, \quad \mathbf{z} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$$

このサンプリング手続きは ε_θ を学習されたデータ密度の勾配とした**ランジュバン動力学**に似ています。

> **初学者向け補足**: ランジュバン動力学とは、確率分布からサンプルを生成するMCMC手法の一種で、分布の勾配（スコア）を使って徐々にサンプルを改善していきます。

## 6. データスケーリングと離散デコーダ（L₀）

### 6.1 データのスケーリング

画像データは {0, 1, ..., 255} の整数値を [-1, 1] に線形スケーリングします。これにより、ニューラルネットワークが標準正規事前分布 p(x_T) から一貫したスケールの入力で動作できます。

### 6.2 離散デコーダ

離散的な対数尤度を得るために、逆過程の最後のステップを離散デコーダとして定義します：

$$p_\theta(\mathbf{x}_0|\mathbf{x}_1) = \prod_{i=1}^{D} \int_{\delta_-(\mathbf{x}_0^i)}^{\delta_+(\mathbf{x}_0^i)} \mathcal{N}(x; \mu_\theta^i(\mathbf{x}_1, 1), \sigma_1^2) \, dx$$

ここで：
- D はデータの次元数
- δ+(x) = ∞ （x = 1 の場合）、x + 1/255 （x < 1 の場合）
- δ-(x) = -∞ （x = -1 の場合）、x - 1/255 （x > -1 の場合）

> **初学者向け補足**: これは連続的なガウス分布を離散的なピクセル値のビンに割り当てる操作です。VAEやPixelCNN++で使われる離散化連続分布と同様の考え方で、変分下界がデータのロスレス符号長として正しく機能することを保証します。

## 7. 簡略化された学習目的関数（Lsimple）

### 7.1 定義

論文の最も重要な実用的貢献の一つが、以下の簡略化された目的関数です：

$$L_{\text{simple}}(\theta) := \mathbb{E}_{t, \mathbf{x}_0, \boldsymbol{\epsilon}} \left[ \|\boldsymbol{\epsilon} - \boldsymbol{\epsilon}_\theta(\sqrt{\bar{\alpha}_t}\mathbf{x}_0 + \sqrt{1-\bar{\alpha}_t}\boldsymbol{\epsilon}, t)\|^2 \right]$$

ここで t は 1 から T の一様分布からサンプリングされます。

### 7.2 標準的な変分下界との違い

- t = 1 の場合：L₀ に対応（離散デコーダの近似）
- t > 1 の場合：元のEq.(12)の重み付けを除いたもの

Lsimple は元の変分下界から重み係数 β²_t / (2σ²_t α_t(1-ᾱ_t)) を除去したものです。この重みの除去は、小さい t（ほとんどノイズのないデータのデノイジング）に対する損失項を相対的に軽視し、大きい t（大量のノイズのデノイジング）に集中させる効果があります。

> **初学者向け補足**: 直感的に言うと、「ほんの少しのノイズを除去する」より「大量のノイズから画像を復元する」ほうがモデルにとって難しく重要なタスクなので、そちらに注力させるのが理にかなっています。結果として、サンプル品質が大幅に向上しました。

### 7.3 学習アルゴリズム（Algorithm 1）とサンプリングアルゴリズム（Algorithm 2）

<img width="597" height="151" alt="Algorithm 1 & 2" src="https://github.com/user-attachments/assets/c2c8b443-41df-4691-9824-0d3bcec32477" />

*Algorithm 1（左）: 学習手続き、Algorithm 2（右）: サンプリング手続き*

**Algorithm 1: 学習**
1. データ x₀ をサンプリング
2. 時刻 t を {1, ..., T} から一様にサンプリング
3. ノイズ ε ~ N(0, I) をサンプリング
4. 勾配降下ステップ：‖ε - ε_θ(√ᾱ_t x₀ + √(1-ᾱ_t)ε, t)‖² を最小化

**Algorithm 2: サンプリング**
1. x_T ~ N(0, I) からスタート
2. t = T から 1 まで：z ~ N(0, I)（t > 1 の場合。t = 1 では z = 0）として x_{t-1} を計算
3. x₀ を返す

### 9.2 アブレーション：パラメータ化と学習目的関数

Table 2 の結果から以下のことがわかりました：

| 発見 | 詳細 |
|---|---|
| **μ̃予測 + 変分下界** | 安定して動作。IS=8.06, FID=13.22 |
| **μ̃予測 + 単純MSE** | 学習が不安定で品質が悪い |
| **ε予測 + 変分下界** | μ̃予測とほぼ同等。IS=7.67, FID=13.51 |
| **ε予測 + Lsimple** | **最高品質。IS=9.46, FID=3.17** |
| **学習可能な対角Σ** | 学習が不安定で品質低下 |

**重要な知見**: ε予測のパラメータ化は、変分下界で学習した場合はμ̃予測とほぼ同等ですが、Lsimple と組み合わせると大幅に優れた結果を生みます。

## 10. 漸進的符号化（Progressive Coding）

### 10.1 ロスレス符号長の分析

CIFAR10モデルの対数尤度は他の尤度ベースモデルと比較して競争力がありません（≤ 3.75 bits/dim vs Sparse Transformer の 2.80 bits/dim）。しかし、学習セットとテストセットのギャップはわずか 0.03 bits/dim で、過学習していないことがわかります。

サンプル品質が高いにも関わらず対数尤度が低い理由は、拡散モデルがロスレス符号長の大部分を**人間には知覚できない微細なディテール**の記述に費やしているためです。

最高品質のCIFAR10モデルの内訳：
- **レート（L₁ + ... + L_T）**: 1.78 bits/dim
- **ディストーション（L₀）**: 1.97 bits/dim
- **RMSE**: 0-255スケールで 0.95

つまり、ロスレス符号長の半分以上が知覚不能な歪みの記述に使われています。

### 10.2 漸進的非可逆圧縮

変分下界の形を反映した漸進的な非可逆符号が定義できます：

<img width="590" height="120" alt="Algorithm 3 & 4" src="https://github.com/user-attachments/assets/9c4fc78a-ad0e-4c51-b9b5-43796a0f8f51" />

*Algorithm 3（左）: x₀の送信手続き、Algorithm 4（右）: 受信手続き*

受信者は任意の時刻 t で部分的な情報 x_t を保持しており、以下で漸進的に推定できます：

$$\mathbf{x}_0 \approx \hat{\mathbf{x}}_0 = \left( \mathbf{x}_t - \sqrt{1-\bar{\alpha}_t}\,\boldsymbol{\epsilon}_\theta(\mathbf{x}_t) \right) / \sqrt{\bar{\alpha}_t}$$

### 10.3 レート歪みプロット

<img width="592" height="150" alt="Figure 5: レート歪み" src="https://github.com/user-attachments/assets/da7e00a9-f7b8-4e4a-a933-0e83fe45dffd" />

*Figure 5: 無条件CIFAR10テストセットのレート歪み対時刻のプロット。歪みは [0, 255] スケールのRMSEで測定。*

レート歪みプロットの低レート領域で歪みが急激に減少していることから、ビットの大部分が知覚不能な歪みに割り当てられていることがわかります。

### 10.4 漸進的生成

ランダムビットからの漸進的伸張として、逆過程中の x̂₀ の変化を観察できます。

<img width="534" height="115" alt="Figure 6: 漸進的生成" src="https://github.com/user-attachments/assets/d3b1e2c6-9cd2-4ce5-939c-79edda893cce" />

*Figure 6: 無条件CIFAR10の漸進的生成（x̂₀ の時間変化、左から右へ）。大規模な画像特徴が先に現れ、細部が後から現れる。*

<img width="480" height="111" alt="Figure 7: 共有潜在変数" src="https://github.com/user-attachments/assets/4475599a-44a9-4364-87ec-15383a6f8f62" />

これは**概念的圧縮**の示唆かもしれません。

### 10.5 自己回帰デコーディングとの接続

変分下界は以下のようにも書き直せます：

$$L = D_{KL}(q(\mathbf{x}_T) \| p(\mathbf{x}_T)) + \mathbb{E}_q \left[ \sum_{t \geq 1} D_{KL}(q(\mathbf{x}_{t-1}|\mathbf{x}_t) \| p_\theta(\mathbf{x}_{t-1}|\mathbf{x}_t)) \right] + H(\mathbf{x}_0)$$

ここで、もし以下のような特殊な設定を考えると：
- 拡散過程の長さ T をデータの次元数と同じに設定
- q(x_t|x₀) が最初の t 座標をマスクした x₀ に全確率を置く
- p(x_T) が空白画像に全確率を置く
- p_θ(x_{t-1}|x_t) が完全に表現力のある条件付き分布

この場合、p_θ の学習は実質的に**自己回帰モデルの学習**になります。

したがって、ガウス拡散モデルは**データ座標の並べ替えでは表現できない一般化されたビット順序を持つ自己回帰モデルの一種**と解釈できます。

重要な点として：
- ガウスノイズは画像に対してマスキングノイズよりも自然
- 拡散長はデータ次元と等しくなくてよい（例：T=1000 で 32×32×3=3072 次元の画像に対応）
- 高速サンプリングのために短く、またはモデルの表現力のために長くできる

## 11. 補間（Interpolation）

<img width="615" height="121" alt="Figure 8: 補間" src="https://github.com/user-attachments/assets/89045bce-8920-4a1f-813b-691ecd4c4c43" />

*Figure 8: 500タイムステップの拡散によるCelebA-HQ 256×256画像の補間*

### 11.1 方法

2つのソース画像 x₀, x'₀ に対し：
1. q を確率的エンコーダとして使用：x_t, x'_t ~ q(x_t|x₀)
2. 潜在空間で線形補間：x̄_t = (1-λ)x₀ + λx'₀
3. 逆過程で画像空間にデコード：x̄₀ ~ p(x₀|x̄_t)

つまり、ノイズを加えたバージョンの画像を線形補間し、逆過程でアーティファクトを除去します。

### 11.2 結果

- 高品質な再構成が可能
- ポーズ、肌の色、髪型、表情、背景などの属性が滑らかに変化する補間が実現
- ただし眼鏡の有無は滑らかに変化しない
- t を大きくすると、より粗く多様な補間になる（t=1000 では新規サンプル）

### 11.3 粗密の補間

<img width="594" height="386" alt="Figure 9: 粗密補間" src="https://github.com/user-attachments/assets/64a762c8-775c-4972-adc2-70b1b6dcf2b2" />

*Figure 9: 拡散ステップ数を変えた粗密補間。ステップ数が多いほど元画像の構造が破壊され、逆過程で補完される。*

- **0ステップ**: ピクセル空間での単純な混合
- **125ステップ**: 細かい粒度の補間
- **500ステップ**: 中程度の粒度の補間
- **1000ステップ**: 元の情報は完全に失われ、補間結果は新規サンプル

## 12. 関連研究

### 12.1 他の生成モデルとの関係

| モデルファミリー | 拡散モデルとの関係 |
|---|---|
| **フロー / VAE** | 構造は似ているが、拡散モデルは q にパラメータがなく、x_T とデータ x₀ の相互情報量がほぼゼロ |
| **スコアマッチング (NCSN)** | ε予測は複数ノイズレベルでのデノイジングスコアマッチングに等価。ただし拡散モデルは対数尤度を直接評価可能 |
| **エネルギーベースモデル** | スコアマッチングとの接続を通じて関連 |
| **自己回帰モデル** | 一般化されたビット順序を持つ自己回帰モデルとして解釈可能 |

### 12.2 NCSNとの重要な違い

本論文のモデルは NCSN（Noise Conditional Score Networks）と以下の点で異なります：

1. **アーキテクチャ**: U-Net + 自己注意 vs RefineNet + 膨張畳み込み。全層に時刻を埋め込み
2. **スケーリング**: 順過程の各ステップで √(1-β_t) 倍にスケールダウンし、入力の一貫したスケーリングを保証
3. **信号の完全な破壊**: D_KL(q(x_T|x₀) ‖ N(0,I)) ≈ 0 を保証し、分布シフトを防止
4. **サンプラーの直接学習**: サンプラーの係数が β_t から厳密に導出され、変分推論でサンプラーを直接学習

## 用語集（初学者向け）

| 用語 | 説明 |
|---|---|
| **FID (Fréchet Inception Distance)** | 生成画像の品質を測る指標。低いほど良い。生成画像と実画像の特徴量分布の距離を測る |
| **IS (Inception Score)** | 生成画像の品質と多様性を測る指標。高いほど良い |
| **NLL (Negative Log-Likelihood)** | 負の対数尤度。モデルがデータをどれだけうまく説明できるかの指標。低いほど良い |
| **bits/dim** | 1次元あたりのビット数。圧縮効率の指標 |
| **KLダイバージェンス** | 2つの確率分布の「距離」を測る尺度（厳密には距離ではない）。同じ分布なら0 |
| **変分下界 (ELBO)** | 対数尤度の下界。最大化することで間接的に尤度を改善 |
| **マルコフ連鎖** | 次の状態が現在の状態のみに依存する確率過程 |
| **ランジュバン動力学** | 確率分布の勾配情報を使ってサンプルを生成するMCMC手法 |
| **スコアマッチング** | データ分布の対数密度の勾配（スコア）を学習する手法 |
| **U-Net** | エンコーダ・デコーダ構造にスキップ接続を加えたCNNアーキテクチャ |
| **EMA (Exponential Moving Average)** | パラメータの指数移動平均。学習の安定化に使用 |
| **RMSE** | 二乗平均平方根誤差。予測と真値の差の指標 |
